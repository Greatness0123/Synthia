# Verified researcher contact atlas for SYNTHIA outreach

This version intentionally contains only public, verifiable contact routes. Where a researcher does not have a clearly public email, the document lists the official lab or university page, public X/Twitter link, and/or LinkedIn profile instead of inventing an address. Use the most official route first.

## How to use this list
- Prefer institutional, lab, or university channels over personal handles.
- If a profile includes a public email, use it only if it is clearly associated with the researcher or official lab.
- If no public email is visible, use the official page, X, or LinkedIn profile instead.
- For cold outreach, keep the message short, relevant, and specific to the researcher?s line of work.
- The response-rate estimates are approximate and assume short, relevant outreach with a clear connection to the researcher?s domain.

## Best-practice outreach order

When contacting a researcher, use this sequence:
1. Official lab or university page
2. Public profile or scholar page
3. X/Twitter if relevant to the domain and active
4. LinkedIn if the researcher is active there
5. Personal email only if it is clearly public on an official page

## Short outreach rule
- Keep the note under 120?180 words.
- Mention only one or two concrete technical overlaps.
- Include the project page and GitHub repo.
- Ask for brief feedback, not a formal meeting.
- Do not mention ?cold outreach? or ?mass mailing.?
